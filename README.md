# Gestion de Compétition Sportive en C

## Présentation

Ce projet est une application développée en langage C permettant de gérer une compétition sportive. Il offre des fonctionnalités de création, de gestion et de suivi des compétitions et des matchs, ainsi que la sauvegarde et le chargement des données.

Le projet a été réalisé dans le cadre d'un travail pratique portant sur les structures de données, l'algorithmique et les bonnes pratiques de programmation en langage C.

## Fonctionnalités

- Création et gestion d'une compétition.
- Ajout et gestion des matchs.
- Affichage des informations relatives à la compétition.
- Sauvegarde des données dans un fichier.
- Chargement des données sauvegardées.
- Interface en ligne de commande.
